## 🌟 Featured Project: City Landing Page Manager

The **City Landing Page Manager** is a production-ready, full-stack platform designed for managing location-based landing pages across **150+ US cities** simultaneously. Built specifically for sales and marketing teams who require programmatic SEO at scale, the platform generates hundreds of unique, localized pages from reusable content templates with zero vendor lock-in.

### 🎯 Key Value Propositions
* **Programmatic SEO** — Generate hundreds of unique, indexable city pages dynamically from reusable templates.
* **Zero Vendor Lock-In** — Standard Next.js application ready to deploy anywhere (AWS, Vercel, Docker, etc.).
* **Admin Dashboard** — Full CRUD management for cities, templates, and custom marketing pages.
* **Built-in Page Builder** — Slide-based content editor supporting 7 distinct block types for custom layouts.
* **Production Security** — Pre-configured with JWT authentication, rate limiting, input sanitization, audit logging, and XSS prevention.

---

## 🛠️ The Technology Stack

Our platform leverages modern, industry-standard technologies to ensure type safety, fast server-side rendering, and frictionless scaling.

### Frontend & UI
* **Next.js 16** — Utilizing the App Router with SSR, static generation, and high-performance API routes.
* **React 18** — High-performance component architecture fully integrated with TypeScript.
* **Tailwind CSS 3 & shadcn/ui** — Utility-first styling paired with beautifully accessible Radix UI primitives.
* **TanStack React Query v5** — Robust server state management and asynchronous caching.

### Backend & DevOps
* **PostgreSQL & Drizzle ORM** — Neon-compatible primary database with type-safe database queries.
* **Zod & drizzle-zod** — Runtime schema validation bridging API inputs and database storage.
* **AWS App Runner** — Optimized for standalone output production deployments.
* **Security Essentials** — Powered by `jose` for secure JWT handling and `scrypt` for password hashing.

## 📦 Core Platform Capabilities

1. **City Location Management:** Supports bulk CSV imports for onboarding hundreds of cities at once, automatic slug generation, and localized field metadata.
2. **Content Template System:** Powerful server-side placeholder substitution architecture using dynamic tags like `{{city}}` and `{{state_name}}`.
3. **Advanced Page Builder:** Full layout control featuring 7 slide modules (Hero, Features, Pricing, Text, Image + Text, CTA, and Custom HTML).
4. **Comprehensive SEO Engine:** Built-in dynamic `sitemap.xml`, `robots.txt`, OpenGraph meta tagging, and automated JSON-LD LocalBusiness structured data schemas.
